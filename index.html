Version 1.0 — Interface automobile web

Interface automobile web inspirée du style visuel des interfaces embarquées modernes. Affichage plein écran en mode paysage, optimisé pour tablettes et PC.

Fonctionnalités : carte Google Maps (Embed API, gratuite) et lecteur Spotify (Web Playback SDK, compte Premium requis).
